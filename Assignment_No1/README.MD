# Assignment 1 – C Programming 🚀

This folder contains my C programming practice programs focused on building strong programming fundamentals and logical thinking.

## 📚 What I Learned

- **Functions:** Creating and calling user-defined functions.
- **Loops:** Using `for` and `while` loops to repeat tasks.
- **Parameters and Return Values:** Passing values to functions and returning results.
- **Conditional Statements:** Using `if-else` to make decisions.
- **Boolean Logic:** Using `typedef`, `TRUE`, and `FALSE` to check conditions.
- **Operators:** Performing division and checking divisibility using `%`.
- **User Input and Output:** Using `scanf()` and `printf()`.
- **Counters:** Printing numbers in descending order and displaying repeated patterns.

## 💻 Programs

| File | Description |
|---|---|
| `program1_1.c` | Divides two numbers using a function |
| `program1_2.c` | Prints “Marvellous” five times |
| `program1_3.c` | Prints numbers from 5 to 1 using a `while` loop |
| `program1_4.c` | Checks whether a number is divisible by 5 |
| `program1_5.c` | Prints a specified number of stars |

## ⚙️ How to Compile and Run

Make sure GCC is installed and available in your terminal.

**Example: Compile a program**

```bash
gcc program1_1.c -o program1_1
```

**Run on Windows PowerShell**

```powershell
.\program1_1.exe
```

Repeat the same steps for other programs by changing the filename.
