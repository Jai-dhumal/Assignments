# Assignment 3 – C Programming 🚀

This folder contains my C programming practice programs created to strengthen my programming fundamentals, logical thinking, and problem-solving skills.

## 📚 What I Learned

- **Loops:** Using `for` loops to print even numbers and find factors.
- **Conditional Statements:** Using `if-else` to check conditions.
- **Functions:** Creating and calling user-defined functions.
- **Operators:** Using modulus (`%`) to check divisibility.
- **Character Handling:** Converting uppercase to lowercase and lowercase to uppercase.
- **Boolean Logic:** Using `typedef`, `TRUE`, and `FALSE` to check whether a character is a vowel.
- **User Input and Output:** Using `scanf()` and `printf()`.

## 💻 Programs

| File | What It Does |
|---|---|
| `program3_1.c` | Prints even numbers up to the given limit |
| `program3_2.c` | Displays factors of a number |
| `program3_3.c` | Displays even factors of a number |
| `program3_4.c` | Converts uppercase characters to lowercase and vice versa |
| `program3_5.c` | Checks whether a character is a vowel |

## ⚙️ How to Compile and Run

Make sure GCC is installed and available in your terminal.

**Step 1: Open the terminal** in this folder.

**Step 2: Compile a program.**

Example for `program3_1.c`:

```bash
gcc program3_1.c -o program3_1
```

**Step 3: Execute the program.**

On Windows:

```bash
.\program3_1.exe
```

Repeat these steps for the other programs by replacing the filename.
